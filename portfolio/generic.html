Proyectos Técnicos

Muestrario de aplicaciones y entornos desplegados durante el curso formativo.

1. Servidor LAMP Multi-Sitio sin Dominio

Configuración integral de un servidor web Apache sobre máquina virtual Linux Ubuntu. Alojamiento simultáneo de múltiples sitios web estáticos mediante estructura de directorios enlazados bajo la dirección IP del host, verificando la compatibilidad de permisos, enlaces relativos y despliegue externo en GitHub Pages.

2. Gestor de Tareas y Almacenamiento Relacional

Desarrollo de un prototipo interactivo para administración de eventos y tareas, estructurado mediante maquetación semántica HTML5, estilos CSS3 responsivos y persistencia simulada de datos.

3. Automatización de Publicación Web

Implementación de flujo de trabajo mediante Git para control de versiones y sincronización bidireccional entre la máquina de desarrollo local y el entorno de producción en GitHub Pages.
